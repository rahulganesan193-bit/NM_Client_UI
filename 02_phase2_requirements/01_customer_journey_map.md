| Stage | User action | System behaviour (this project) | Pain removed |
|-------|-------------|---------------------------------|--------------|
| 1. Open form | Create New incident | onLoad message guides entry | Not knowing what to enter |
| 2. Describe | Enter short description, category | Category change clears subcategory | Wrong subcategory |

| 4. Submit | Click Submit | onSubmit validates description | Vague tickets |
| 5. Work | Set On Hold | Hold reason required | Unexplained holds |
| 6. Resolve | Set Resolved | Resolution code and notes required | Empty closures |
